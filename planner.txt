AGENTIC TASK EXECUTOR — DAY-WISE PLANNER
======================================

Project Name:
Agentic Task Executor

Repo:
agentic-task-executor

Goal:
Build a minimal agentic AI system from scratch that can:
- take a high-level task
- decompose into steps using an LLM
- execute steps iteratively using tools
- maintain memory (steps/results/logs)
- output traceable execution summary

Scope Rules:
- No vector DB
- No UI
- No LangChain/CrewAI/AutoGPT frameworks
- Pure Python logic + OpenAI API
